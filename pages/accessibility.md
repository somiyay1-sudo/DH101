# Accessibility

Accessibility improvement
This site was built by Yugen Somiya for DH 101. I have tried to make it accessible by focusing on structure, text, color, and navigation.

On this page, I have implemented several improvements to enhance accessibility: I have increased the color contrast of the background to make the text easier to read; I have enlarged the font size; and we have added supplementary explanatory text. Furthermore, to ensure that users can return to the Home page from any other page, we have added a "Click here to return Home" link: [Click here to return Home](../index.html).

Accessibility Improvement. I improved the HTML structure by using proper semantic elements like section, article, and nav so screen readers can understand the page structure. I added meaningful alt text for informative images and used empty alt text for decorative ones so visually impaired users can understand image content without extra noise. I increased color contrast to meet WCAG guidelines for readability in low-vision and low-light contexts. I ensured keyboard accessibility by making interactive elements reachable by the Tab key and adding visible focus indicators with CSS. I replaced vague link text with descriptive wording so screen reader users can navigate links effectively. I improved text readability by breaking long paragraphs into shorter ones, using clear sentence structure, and keeping line spacing comfortable.
